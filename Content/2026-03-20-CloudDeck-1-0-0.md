CloudDeck is a brand new iOS client for Nextcloud Deck!


- Create, edit, and delete boards, lists, and cards
- Archive boards and cards
- Reorder boards, lists, and cards using drag and drop
- On cards:
  - Edit title
  - Edit description using markdown
  - Add or delete labels, due date, and assigned users
  - Mark cards as done
